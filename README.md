# Sparkle: The Timeland (PWA)
Jogo 3D (Three.js) com dublagem em português. Legendas em português por enquanto.

## Arquivos
index.html, lines.js (falas), manifest.json, sw.js, icons/, dub/ (001-145.mp3, falta só a 035), the_missing_time.mp3

## Publicar
1. Crie um repositório no GitHub e envie TODOS os arquivos desta pasta (mantenha as pastas `dub` e `icons`).
2. Settings → Pages → Branch `main` / root → Save. Aguarde o link https://SEU-USUARIO.github.io/SEU-REPO/
3. Abra o link no celular e teste (precisa ser HTTPS).
4. Em pwabuilder.com cole o link, gere o pacote Android e siga as instruções.

## Controles
Joystick à esquerda, arraste a tela à direita para girar a câmera. Botões: Atacar/Falar, Pular, Montar/Descer (aparece perto do cavalo) e Menu.
